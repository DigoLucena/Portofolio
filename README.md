# Portfólio Profissional e Acadêmico — Diogo de Lucena Pereira

Projeto desenvolvido para a atividade de Front End com HTML5 semântico e CSS3.

## Requisitos atendidos

- HTML5 semântico: `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`.
- CSS3 para cores, tipografia, espaçamento, bordas, sombras e efeitos.
- Flexbox para organização dos componentes.
- Media Queries para responsividade.
- Separação entre HTML e CSS.
- Estrutura organizada de arquivos.
- Apresentação de informações acadêmicas e profissionais.
- Seções: Início, Sobre, Formação, Competências, Projetos, Experiência e Contato.

## Como executar

1. Extraia os arquivos.
2. Abra o arquivo `index.html` em um navegador.
3. Para personalizar, altere os links de e-mail, LinkedIn e GitHub no `index.html`.

## Observação

A imagem de perfil não foi utilizada para manter o projeto independente de arquivos externos. O círculo com as iniciais "DL" funciona como identidade visual.
